# Product Contract: Resume Web

## Purpose
A professional, high-performance personal resume and portfolio.

## Key Features
- Dynamic personal content (Experience, Skills, Projects).
- Interactive exploration (Terminal, AI Chatbot).
- Print-to-PDF generation (resume application ready).

## Constraints
- **Performance:** No heavy bloat. Next.js 16 SSR + Tailwind v4.
- **Maintainability:** Minimal dependency footprint.
- **Device Support:** Fully responsive, optimized for mobile reading.
