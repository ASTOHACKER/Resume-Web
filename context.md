# Project Context: Resume Web

## Overview
Personal portfolio website for Narudom O-kart, PSU IT Student. 
Built with Next.js 16 (App Router), Tailwind CSS v4, and TypeScript.

## Core Features
- Editorial-style resume layout (Archive/Zine aesthetic).
- Print-to-PDF optimization.
- Interactive elements: AI Chatbot, Terminal emulation.
- Theme: Dark-centric, minimalist.

## Tech Stack
- Next.js 16.2.9
- React 19.2.4
- Tailwind CSS v4
- Framer Motion (Animations)
- Lucide React (Icons)
- Fonts: Prompt (Thai/Display), Outfit (Latin/Body)

## Development Guidelines
- Mobile-first approach.
- `.no-print` utility for UI clutter removal.
- Component-based architecture (`src/components/`).
- Use `globals.css` for centralized design tokens.
