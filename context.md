# Resume Web Context

## Project Overview
Next.js 16 (App Router) + React 19 + Tailwind CSS v4.
Personal portfolio and resume web application.

## Key Components
- **Core Layouts:** `src/app/layout.tsx`, `src/app/page.tsx`
- **UI Components:** `src/components/` (Hero, About, Experience, Projects, Skills, Contact, Navbar, FloatingActions, AIChatbot, Terminal, etc.)
- **Styling:** Tailwind CSS v4 (globals.css)

## Stack
- Framework: Next.js 16
- UI: React 19, Tailwind CSS v4, Lucide React, Framer Motion
- Project Structure:
  - `src/app/`: App router routes
  - `src/components/`: Modular React components
  - `public/`: Assets
